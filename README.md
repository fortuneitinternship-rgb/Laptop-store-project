# 💻 LaptopHub

LaptopHub is a responsive e-commerce frontend application
for browsing, comparing and purchasing laptops.

## 🚀 Technologies

- React.js
- Vite
- JavaScript
- Bootstrap
- Bootstrap Icons
- React Router DOM
- CSS
- Git
- GitHub
